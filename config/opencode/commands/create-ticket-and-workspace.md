description: Create a Linear ticket for the problem and move the session to a new workspace
---

1. Read `~/.config/opencode/commands/create-ticket.md`.
2. Follow its steps 1–2 to create the ticket.
3. Create a new workspace for the task. Follow the same path pattern as the other workspaces.
   - Do not use the `feature/` prefix for the branch or the workspace.
   - Do not use the branch name that Linear generates because it is too long. Make a short name yourself. It only needs to tell one branch from another. It does not need to describe the whole problem like a ticket title does.
4. Move this session into the new workspace.
5. Name the session based on the ticket.
6. Give me the link to the ticket as last line of your response.
