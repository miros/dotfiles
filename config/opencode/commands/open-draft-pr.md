---
description: Commit changes, open a draft PR, and request a Copilot review
---

1. Commit all unstaged changes in one or more commits.
2. Open a draft PR.
3. Request a review from Copilot with the Balanced effort level.
4. Give me the link to the PR.

The PR description must use this format:

- **Link to ticket**
- **Problem:** Describe it at a conceptual level. Use 5 sentences max.
- **Solution:** Explain it at a conceptual level. Keep it brief and easy to scan.
- **Tests:** List the readable names of the tests added, grouped by file.
